# Activity Monitor
Inspect processes and resource use.

## Use the app
1. Open Activity Monitor.
2. Inspect process, CPU, memory, disk, and network information.
3. Identify the application responsible for activity before ending a process.

## Expected result and troubleshooting
Ending a process can discard its unsaved work. These guest counters do not measure host energy use or end-to-end input latency. Use reproducible benchmarks for performance claims.

See [Desktop and windows](desktop-windows.md) for shared shortcuts and [Recovery](reference-recovery.md) if the app cannot open.
