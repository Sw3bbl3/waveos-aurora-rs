# GINA Apps
Install and manage native application packages.

## Use the app
1. Open a .gina file in Files.
2. Review the app name, developer, version, and install/update action.
3. Install the package and choose Open App. Find installed apps in Launcher and Spotlight.
4. For an offline example, open `/System/Developer/Examples/AuroraKitGallery.gina`.

## Expected result and troubleshooting
Updates keep app data. Uninstall retains data unless deletion is explicitly selected. GINA validates package structure and ABI, but does not provide package signatures or app-data isolation. Install only packages you trust.

See [Desktop and windows](desktop-windows.md) for shared shortcuts and [Recovery](reference-recovery.md) if the app cannot open.
