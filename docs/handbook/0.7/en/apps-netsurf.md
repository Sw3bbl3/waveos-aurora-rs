# NetSurf
A small, quick browser for the web and local HTML documents, without JavaScript.

## Use the app
1. Open NetSurf from the launcher or Seek. When neither Voyage nor Firefox is on the disk, the dock's browser, `.html` files and web links in Learn and About open NetSurf instead.
2. Click the address bar, type an address and press Enter. Ctrl+U clears the address bar. The centre of the window's top edge is the window handle, so click the address bar to either side of it.
3. Use the toolbar arrows, Alt+Left/Right or a mouse's side buttons to go back and forward. The reload and stop buttons are next to them.
4. Scroll with the wheel, the scroll bars, the arrow keys or Page Up/Down. Ctrl+plus/minus/0 change the zoom.
5. For another page at the same time, open another NetSurf window from the launcher.

## Expected result and troubleshooting
NetSurf shows HTML and CSS pages with pictures, over HTTP and HTTPS, and keeps cookies. It does not run JavaScript: pages that need scripts may be incomplete or ask you to turn JavaScript on; use [Voyage](apps-voyage.md) for those. SVG support is basic. If a secure page shows a privacy error, check the date and time in Settings; certificate errors stop the page until you choose Proceed.

See [Desktop and windows](desktop-windows.md) for shared shortcuts and [Recovery](reference-recovery.md) if the app cannot open. For JavaScript, use `js` in [Terminal](apps-terminal.md).
