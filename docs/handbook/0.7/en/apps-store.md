# Store
Find, install, update and remove apps and games.

## Set up a repository
The Store shows apps from repositories you choose; WaveOS comes without any. Open the Store and type a repository's address (for example `https://example.com/apps/`) in the box, then choose **Add Repository**. You can also add and remove repositories in Settings → Software Update. Adding one needs an administrator.

## Find and install an app
1. Browse **Discover**, pick a category in the sidebar, or type in the search field.
2. Choose an app to see its page: pictures, what it does, what's new, its size and the permissions it asks for.
3. Choose **For everyone** or **Only for me**, then **Get**. Installing for everyone asks for an administrator's password.
4. While it downloads you can pause, resume or cancel it. When it is done, choose **Open**. Games appear in Wave Play with your other games.

## Updates and your library
**Updates** lists newer versions of your apps; choose **Update All** to install them one after another. If a new version of WaveOS is available it appears there too and opens Software Update. **Library** lists what is installed, for whom, and lets you open or remove each app. On an app's page, **Revert** goes back to the version an update replaced.

## Keyboard and controller
Use the arrow keys to move between apps, Enter to open, and Escape to go back. With a game controller, the d-pad moves, A opens, B goes back, and the shoulder buttons move between sections.

## Expected result and troubleshooting
Everything the Store installs is checked against its repository's signature and its publisher's signature before any file is written; a damaged or altered download is refused and deleted. If the Store says you are offline, it shows what it saved last time; installing needs the network. A repository whose catalogue is older than one seen before, or out of date, is refused: tell whoever runs it.

See [Software Update](system-updates.md) for WaveOS itself and [Recovery](reference-recovery.md) if an app cannot open.
