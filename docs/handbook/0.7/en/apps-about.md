# About and Welcome
Check the running version and revisit the introduction.

## Use the app
1. Choose About WaveOS Aurora from the Aurora menu.
2. Check the version, kernel, CPU, and memory information.
3. Open Welcome from Launcher; Get Started opens Learn.

## Expected result and troubleshooting
If About shows an older version, verify which disk or ISO your VM booted. Replacing a source checkout does not update an already copied ISO.

See [Desktop and windows](desktop-windows.md) for shared shortcuts and [Recovery](reference-recovery.md) if the app cannot open.
