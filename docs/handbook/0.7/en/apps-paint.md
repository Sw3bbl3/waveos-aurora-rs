# Paint
Draw and save a PNG image.

## Use the app
1. Open Paint, select a drawing tool and a colour.
2. Drag on the canvas to draw.
3. Save the result as a PNG in Pictures and reopen it in Preview.

## Expected result and troubleshooting
Use a writable path and keep a saved copy before closing. If the result is missing, check the chosen filename and volume.

See [Desktop and windows](desktop-windows.md) for shared shortcuts and [Recovery](reference-recovery.md) if the app cannot open.
