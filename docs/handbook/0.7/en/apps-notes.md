# Notes
Write and save plain-text documents.

## Use the app
1. Open Notes and type a short document.
2. Use Ctrl+A/C/X/V for selection and clipboard; Ctrl+Z and Ctrl+Shift+Z undo and redo.
3. Press Ctrl+F to find text, or use the font and size controls.
4. Press Ctrl+S and choose a writable location when saving a new document. Reopen it in Files to verify the save.

## Expected result and troubleshooting
Closing an edited document asks what to do with unsaved changes. Font choices affect editing appearance; Notes is not a rich-text word processor. Save outside /System.

See [Desktop and windows](desktop-windows.md) for shared shortcuts and [Recovery](reference-recovery.md) if the app cannot open.
