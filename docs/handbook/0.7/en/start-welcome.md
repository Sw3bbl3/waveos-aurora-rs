# Welcome to WaveOS Aurora
WaveOS is an experimental x86-64 operating system with a native desktop, isolated applications, persistent storage, and a small web browser. Version 0.7 adds Learn and improves everyday desktop interaction.

## Get started
1. Read [Installation and updating](start-installation.md) and choose a disk image or UEFI ISO.
2. Boot the image. Open **Learn** from Launcher or choose **Get Started** in Welcome.
3. Open [Desktop and windows](desktop-windows.md) to learn the shortcuts.
4. Try [Files](apps-files.md), [Notes](apps-notes.md), and [Settings](apps-settings.md).

The expected result is a working desktop where each app runs as a separate process. This is a development system; read [Known limitations](reference-limitations.md) before using it on hardware.

## Find your way
Learn contains offline user guides, app instructions, developer documentation, and release notes. Switch between English and Français (Canada) without leaving the article. The rest of the desktop currently uses English labels.

## Troubleshooting
If an app closes unexpectedly, open it again and inspect the crash report. Use [Troubleshooting and recovery](reference-recovery.md) for boot, display, and persistence problems.
