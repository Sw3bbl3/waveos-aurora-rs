# Terminal
Run programs and combine commands.

## Use the app
1. Open Terminal and type `help`.
2. Try `ls`, `pwd`, `ps`, `df`, and `neofetch`.
3. Write `echo hello > /Documents/hello.txt`, then `cat /Documents/hello.txt`.
4. Try `ls -l | grep txt` and `cat /Documents/hello.txt | wc`.

## Expected result and troubleshooting
Use Tab completion and Ctrl+C to interrupt. Pipelines, >, >>, &&, || and semicolon lists are supported. This is aurora-sh, not a full POSIX shell; consult the command guide for supported tools.

See [Desktop and windows](desktop-windows.md) for shared shortcuts and [Recovery](reference-recovery.md) if the app cannot open.
