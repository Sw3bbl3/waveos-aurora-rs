# Calculator
Perform everyday arithmetic.

## Use the app
1. Open Calculator from Launcher.
2. Enter numbers and choose an arithmetic operation.
3. Evaluate the expression and clear it before a new calculation.

## Expected result and troubleshooting
Spotlight also evaluates expressions such as `12*7+1`. Check the entered expression if the result is unexpected; this is not a symbolic algebra system.

See [Desktop and windows](desktop-windows.md) for shared shortcuts and [Recovery](reference-recovery.md) if the app cannot open.
