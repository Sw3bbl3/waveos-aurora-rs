# Software Update
Keep WaveOS itself up to date.

## Check and install
1. Open Settings → Software Update and choose **Check Now**. WaveOS also checks by itself and shows a notification when something is new.
2. Read what's new and choose **Download**. Only the files that changed are downloaded; you can pause and resume.
3. Choose **Install**. The new version is written beside the one you are using and every file is checked; nothing changes yet.
4. Choose **Restart Now**, or later **Update and Restart** in the power menu.

## If the new version doesn't start
Your computer tries the new version up to three times. If it never reaches the desktop, the previous version starts by itself and Software Update tells you which version failed. Your files and settings are never part of an update.

## Automatic updates and repositories
Turn **Check for updates automatically** and **Download system updates automatically** on or off. Installing always waits for you. The **Repositories** list is where the Store and Software Update look; adding or removing one needs an administrator.

See [Store](apps-store.md) for apps and [Recovery](reference-recovery.md) if WaveOS does not start.
