# GINA Apps
Installez et gérez les paquets d’applications natives.

## Utiliser l’application
1. Ouvrez un fichier .gina dans Files.
2. Vérifiez le nom, le développeur, la version et l’action d’installation ou de mise à jour.
3. Installez le paquet, puis choisissez Open App. Les applications installées apparaissent dans Launcher et Spotlight.
4. Pour un exemple hors ligne, ouvrez `/System/Developer/Examples/AuroraKitGallery.gina`.

## Résultat attendu et dépannage
Les mises à jour conservent les données. La désinstallation les conserve aussi, sauf si leur suppression est explicitement sélectionnée. GINA valide la structure et l’ABI, mais ne fournit ni signature des paquets ni isolation des données entre applications. Installez seulement des paquets auxquels vous faites confiance.

Voir [Bureau et fenêtres](desktop-windows.md) pour les raccourcis communs et [Récupération](reference-recovery.md) si l’application ne s’ouvre pas.
