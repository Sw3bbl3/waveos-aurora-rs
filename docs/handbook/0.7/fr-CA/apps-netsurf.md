# NetSurf
Un petit navigateur rapide pour le Web et les documents HTML locaux, sans JavaScript.

## Utiliser l’application
1. Ouvrez NetSurf depuis le lanceur ou Seek. Quand Firefox n’est pas sur le disque, le navigateur du dock, les fichiers `.html` et les liens Web de Learn et d’About ouvrent NetSurf à la place.
2. Cliquez dans la barre d’adresse, tapez une adresse et appuyez sur Entrée. Ctrl+U vide la barre d’adresse. Le centre du bord supérieur de la fenêtre est la poignée de la fenêtre : cliquez dans la barre d’adresse de part et d’autre.
3. Utilisez les flèches de la barre d’outils, Alt+Gauche/Droite ou les boutons latéraux de la souris pour reculer et avancer. Les boutons Recharger et Arrêter sont à côté.
4. Faites défiler avec la molette, les barres de défilement, les flèches ou Page préc./Page suiv. Ctrl+plus/moins/0 règle le zoom.
5. Pour une autre page en même temps, ouvrez une autre fenêtre NetSurf depuis le lanceur.

## Résultat attendu et dépannage
NetSurf affiche les pages HTML et CSS avec leurs images, en HTTP et HTTPS, et conserve les témoins. Il n’exécute pas JavaScript : les pages qui en ont besoin peuvent être incomplètes ou demander d’activer JavaScript; utilisez [Firefox](apps-firefox.md) pour celles-là. La prise en charge de SVG est sommaire. Si une page sécurisée affiche une erreur de confidentialité, vérifiez la date et l’heure dans Settings; une erreur de certificat bloque la page tant que vous ne choisissez pas Proceed.

Voir [Bureau et fenêtres](desktop-windows.md) pour les raccourcis communs et [Récupération](reference-recovery.md) si l’application ne s’ouvre pas. Pour JavaScript, utilisez `js` dans [Terminal](apps-terminal.md).
