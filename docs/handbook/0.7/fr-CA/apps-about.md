# About and Welcome
Vérifiez la version en cours et retrouvez l’introduction.

## Utiliser l’application
1. Choisissez About WaveOS Aurora dans le menu Aurora.
2. Vérifiez la version, le noyau, le processeur et la mémoire.
3. Ouvrez Welcome dans Launcher; Get Started ouvre Learn.

## Résultat attendu et dépannage
Si About affiche une ancienne version, vérifiez le disque ou l’ISO utilisé par la machine virtuelle. Mettre le code source à jour ne modifie pas un ISO déjà copié.

Voir [Bureau et fenêtres](desktop-windows.md) pour les raccourcis communs et [Récupération](reference-recovery.md) si l’application ne s’ouvre pas.
