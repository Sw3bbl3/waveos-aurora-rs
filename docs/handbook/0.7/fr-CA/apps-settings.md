# Settings
Personnalisez le bureau et configurez le système.

## Utiliser l’application
1. Ouvrez Settings et choisissez Appearance, Desktop & Dock ou Accessibility.
2. Réglez le thème, l’accent, le fond d’écran, le verre, le Dock, Reduce Motion, Reduce Transparency ou Increase Contrast.
3. Ctrl+F recherche une page. Tab/Maj+Tab parcourt la recherche, la navigation et les commandes.
4. Dans Display, choisissez un mode et confirmez Keep seulement si le bureau reste utilisable. Redémarrez pour vérifier les préférences enregistrées.

## Résultat attendu et dépannage
Les autres pages couvrent les dispositions du clavier, la répétition, la date, l’heure, le son, les notifications, le réseau et les renseignements système. QEMU VGA permet les changements de mode immédiats; d’autres écrans peuvent nécessiter un redémarrage. Un stockage plein ou en lecture seule peut empêcher l’enregistrement.

Voir [Bureau et fenêtres](desktop-windows.md) pour les raccourcis communs et [Récupération](reference-recovery.md) si l’application ne s’ouvre pas.
